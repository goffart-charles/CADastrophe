# Mesures OCCT

Extension locale de l'API v1, sans donnée documentaire ni dépendance envers Primitives. **Évaluation → Mesures** et la palette Ctrl+K ouvrent les mesures de distance minimale, longueur d'arête, rayon analytique, angle minimal et aire.

Les calculs portent sur la sélection topologique native et ne modifient pas le document.

Les cinq fichiers SVG de `icons/` sont des dessins vectoriels originaux du projet. Qt fournit leurs variantes HiDPI et désactivées.
